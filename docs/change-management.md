# Change and Configuration Management Plan

## Project
AI-Powered Student Support Chatbot

## Change Management Process

All proposed project changes must follow a formal
change management procedure.

### Step 1: Submit Change Request
The project team submits a change request.

### Step 2: Impact Assessment
The project manager evaluates:
- Project scope
- Schedule
- Budget
- Quality
- Security risks

### Step 3: Approval
The Change Control Board reviews and approves
or rejects the proposed change.

### Step 4: Implementation
Approved changes are implemented using GitHub
branches and version control.

### Step 5: Testing
Changes are tested before merging into the main branch.

### Step 6: Documentation
Approved changes are recorded in the change log.

## Configuration Management

GitHub is used to maintain:
- Project documentation
- Version history
- Change tracking
- Pull requests
- Release records

## Version Control Strategy

Main branch: Approved project baseline.

Feature branches: Proposed changes.

Pull requests: Review and approval before merging.
